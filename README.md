# Problem #3: Marketing-to-Revenue Attribution Intelligence

## Overview
A business analytics system designed to trace the customer journey from multi-channel campaign exposure through lead generation, deal conversion, and closed revenue.

### Features
- **Multi-Touch Attribution**: First-Touch, Last-Touch, Linear, Time-Decay, and U-Shaped models.
- **Funnel Drop-off Analysis**: Evaluates conversion leakages from visitor to lead to closed-won revenue.
- **Channel ROAS & Cost Allocation**: Compares ad spend against multi-touch attributed revenue to prevent cutting high-value top-of-funnel channels.
- **Interactive Web Dashboard**: Real-time charts, metric summaries, and actionable AI recommendations.

## Running the Application

```bash
python main.py
```
